## Description

PulseKey is a compact Windows input studio by @BraxFFA. Choose a visible desktop window, select a keyboard key or mouse button, and hold or repeat it at an adjustable interval. The action runs only while your chosen window is in front.

Use Macro studio to build a sequence of key presses, mouse clicks, and waits. Edit and reorder steps, then save a macro locally and load it later. Switch among 15 dark themes to make the workspace your own.

F8 starts or pauses a quick action. F9 stops and releases held input. F11 enters or exits full screen. Status shows Idle, Armed, or Active so you can tell when output is running.

PulseKey uses Windows `SendInput` to create synthetic input. It does not produce physical hardware input or bypass protected apps and games. Some apps may ignore or reject its output. Use it only where automation is permitted.

PulseKey has no account, background service, telemetry, or automatic network requests. Settings and saved macros stay on your device.
